# 🎮 Мини-игры

Интерактивный веб-сайт с коллекцией из 6 мини-игр на любой вкус. Проект создан для демонстрации навыков верстки, адаптивного дизайна и работы с JavaScript.

## 🚀 Демо (Посмотреть вживую)
👉 [Ссылка на GitHub Pages](https://logdinghudra440.github.io/Site-mini-games/)

## 🛠 Технологии
В проекте использованы следующие технологии:
* **HTML5** — семантическая верстка.
* **CSS3 (SCSS)** — стилизация, использование переменных, вложенности и миксинов.
* **Адаптивная верстка** — сайт корректно отображается как на десктопах, так и на мобильных устройствах (Media Queries).
* **JavaScript (Vanilla JS)** — вся игровая логика написана на чистом JS без сторонних библиотек.

## 🎯 Реализованный функционал
Сайт включает в себя 6 полностью рабочих игр:
1. **Угадай число** — игра, где нужно угадать случайное число от 1 до 100.
2. **Простая арифметика** — решение случайных примеров на сложение, вычитание, умножение и деление.
3. **Переверни текст** — забавная утилита, переворачивающая введенный текст.
4. **Камень, ножницы, бумага** — классическая игра против компьютера.
5. **Простая викторина** — проверка знаний с вариантами ответов.
6. **Генератор случайных цветов** — клик по кнопке меняет фон карточки на случайный цвет.

## 🎨 Особенности интерфейса
* Плавные анимации при наведении (hover-эффекты).
* Бесконечная бегущая строка (marquee) с названиями игр.
* Красивые фоновые изображения (звезды, паттерны), реализованные через CSS.
* Блок с карточками игр, который скрывается на мобильных устройствах для удобства навигации (остается только список самих игр).
